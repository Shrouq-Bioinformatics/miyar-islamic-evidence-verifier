## لقطة التسجيل

- المدة المستهدفة: 85–90 ثانية، والحد الأقصى بحسب شروط المسابقة يُراجع قبل التصدير.
- نسبة 16:9، تكبير 100–110%، مؤشر هادئ، وصوت واضح.
- استخدم الحالة أعلاه لضمان الإحالة؛ لا تستخدم بيانات حقيقية.
- أخفِ شريط المتصفح والإشعارات وأي أسرار.
- مصدر العرض مكتمل في 16 شريحة وعُزّز بلقطة التطبيق والنتائج وخطة الاستمرار. بقي تصديرا PDF وPowerPoint السابقان محفوظين لأن `exportSlides` يفشل بعد التعديلات؛ يلزم إعادة التصدير القياسي قبل التسليم. الفيديو المصدّر `submission/miyar-demo.mp4` مدته 87 ثانية بنسبة 16:9، وهذا الملف نص التعليق الصوتي.
