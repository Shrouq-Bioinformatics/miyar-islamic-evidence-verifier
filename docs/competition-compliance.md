# مطابقة مِعيار لشروط تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026

تاريخ المراجعة: 23 سبتمبر 2026. المرجع: «دليل المشارك» المرفق، 44 صفحة.

## القرار التنفيذي

مِعيار **مطابق للمسار الرابع من حيث المشكلة والجمهور واتجاه الحل**، ولديه واجهة تعمل، تحليل AI فعلي، استرجاع مقتطفات قابلة للتتبع، حفظ مشترك، رابط عرض، وثائق، عرض تقديمي، حزمة مصدر، مستودع GitHub عام، وفيديو لا يتجاوز دقيقتين. ما زالت هناك متطلبات تسليم خارجية لا يمكن ادعاء اكتمالها دون تنفيذها: التقييم المحكم، إعادة نشر آخر نسخة، وتحديث تصدير العرض.

## ما تم التحقق منه فعليًا

- نجحت 6 اختبارات API حاسمة، منها منع اعتماد نسبة مختلقة للبخاري وخفض مخرجات المزود غير الموثقة.
- نجحت رحلة واجهة كاملة: تدقيق مطالبة، حفظها، إعادة تحميلها، قرار المراجعة، تصدير JSON، وطباعة تقرير عربي.
- نجح العرض على عرض جوال 390 بكسل.
- نجح بناء الواجهة والعرض، والتحقق من manifest العرض ذي 16 شريحة.
- فُحص أرشيف المصدر بقائمة سماح مع استبعاد الأسرار وملفات البيئة والتبعيات المبنية.

## الأعمال المانعة قبل التسليم

1. إجراء اختبار علمي بمراجعين مختصين وتوثيق النتائج أو حذف أي ادعاء أثر.
2. إرفاق فيديو 16:9 لا يتجاوز دقيقتين في نموذج التسليم.
3. إرفاق رابط مستودع GitHub العام في نموذج التسليم.
4. إعادة نشر آخر تغييرات المنتج واختبار الرابط وجميع الوظائف من نافذة خاصة.
5. تعبئة بيانات الفريق، المسؤوليات، رقم المشاركة، وإجراء مراجعة شرعية وقانونية نهائية.
6. إصلاح `exportSlides` وإعادة تصدير PDF وPowerPoint بالطريقة القياسية، ثم مراجعة أن التصدير يعكس مصدر العرض المعزّز.
