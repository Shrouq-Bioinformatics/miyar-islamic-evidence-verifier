# مطابقة مِعيار لشروط تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026

تاريخ المراجعة: 23 سبتمبر 2026. المرجع: «دليل المشارك» المرفق، 44 صفحة.

## القرار التنفيذي

مِعيار **مطابق للمسار الرابع من حيث المشكلة والجمهور واتجاه الحل**، ولديه واجهة تعمل ورابط عرض ووثائق وعرض تقديمي وحزمة مصدر. لكنه **غير مستوفٍ بعد للتسليم النهائي** لأن شروط المسابقة ترفض الاكتفاء بنموذج أولي، وتطلب توظيفًا فعليًا للذكاء الاصطناعي، ومستودع GitHub عامًا، وفيديو لا يتجاوز دقيقتين. النسخة الحالية تعمل بقواعد محلية معلنة، بلا استرجاع نصوص أو تحقق مصدر خاص بالمطالبة.

## ما تم التحقق منه فعليًا

- نجحت 6 اختبارات API حاسمة، منها منع اعتماد نسبة مختلقة للبخاري وخفض مخرجات المزود غير الموثقة.
- نجحت رحلة واجهة كاملة: تدقيق مطالبة، حفظها، إعادة تحميلها، قرار المراجعة، تصدير JSON، وطباعة تقرير عربي.
- نجح العرض على عرض جوال 390 بكسل.
- نجح بناء الواجهة والعرض، والتحقق من manifest العرض ذي 16 شريحة.
- فُحص أرشيف المصدر بقائمة سماح مع استبعاد الأسرار وملفات البيئة والتبعيات المبنية.

## الأعمال المانعة قبل التسليم

1. تفعيل AI حقيقي صالح وإظهار وظيفته الفعلية في السيناريو الأساسي.
2. إضافة استرجاع من مصادر مسموح بها مع مقطع محدد ورابط ونسخة/تاريخ، لا مجرد رابط فهرس.
3. إجراء اختبار علمي بمراجعين مختصين وتوثيق النتائج أو حذف أي ادعاء أثر.
4. إرفاق فيديو 16:9 لا يتجاوز دقيقتين في نموذج التسليم.
5. إنشاء مستودع GitHub عام وإرفاق التراخيص والحقوق وسجل المصادر.
6. إعادة نشر آخر تغييرات المنتج واختبار الرابط وجميع الوظائف من نافذة خاصة.
7. تعبئة بيانات الفريق، المسؤوليات، رقم المشاركة، وإجراء مراجعة شرعية وقانونية نهائية.
8. إصلاح `exportSlides` وإعادة تصدير PDF وPowerPoint بالطريقة القياسية، ثم مراجعة أن التصدير يعكس مصدر العرض المعزّز.
